# Verificacion normativa: ¿Cuánto tiempo tiene el trabajador para presentar la incapacidad?

## Proposiciones a verificar

### claim_id: LAB-0933-001
- afirmacion_guia: Naturalmente que primero debe surtirse la autorización para luego proceder 
a realizar el pago dentro de los términos ya señalados.
- pagina_guia: 826
- norma_citada: Articulo 2; decreto 780
- resultado: norma_identificada_requiere_contraste
### claim_id: LAB-0933-002
- afirmacion_guia: La ley no establece un plazo para que el trabajador presente la incapacidad 
al empleador, así que no existe un límite temporal para ello.
- pagina_guia: 826
- norma_citada: Articulo 2; decreto 780
- resultado: norma_identificada_requiere_contraste
### claim_id: LAB-0933-003

pronto como ocurre el quebranto de salud, ya que el artículo 2.2.3.3.4 del 
decreto 780 de 2016 no permite expedir incapacidad
- pagina_guia: 826
- norma_citada: Articulo 2; decreto 780
