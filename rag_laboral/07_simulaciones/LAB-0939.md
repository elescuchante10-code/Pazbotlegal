# Simulaciones: ¿Cuánto tiempo tiene el trabajador para presentar la incapacidad?

## Caso favorable al trabajador
Trabajador que cumple los elementos de ¿cuánto tiempo tiene el trabajador para presentar la incapacidad?. La regla aplica y la respuesta es afirmativa.

## Caso favorable a la empresa
Caso semejante donde faltan elementos centrales de ¿cuánto tiempo tiene el trabajador para presentar la incapacidad?. La regla no aplica.

## Caso ambiguo
Caso con indicadores a favor y en contra de ¿cuánto tiempo tiene el trabajador para presentar la incapacidad?. Depende de hechos decisivos a verificar. Requiere analisis adicional.

## Caso excluido
Situacion que no cumple ningun elemento de ¿cuánto tiempo tiene el trabajador para presentar la incapacidad?. La regla no aplica y no hay derecho ni obligacion derivada.

## Caso excepcional

## Caso con prueba suficiente
El consultante presenta contrato, desprendibles, correos y testimonios que confirman los hechos de ¿cuánto tiempo tiene el trabajador para presentar la incapacidad?. La conclusion es viable con la prueba disponible.

## Caso con prueba insuficiente
El consultante no tiene contrato escrito ni comprobantes sobre ¿cuánto tiempo tiene el trabajador para presentar la incapacidad?. La conclusion depende de indicios y requiere recolectar mas evidencia.
