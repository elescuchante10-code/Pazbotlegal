# Simulaciones: ¿Cuántas veces se puede prorrogar una incapacidad laboral?

## Caso favorable al trabajador
Trabajador que cumple los elementos de ¿cuántas veces se puede prorrogar una incapacidad laboral?. La regla aplica y la respuesta es afirmativa.

## Caso favorable a la empresa
Caso semejante donde faltan elementos centrales de ¿cuántas veces se puede prorrogar una incapacidad laboral?. La regla no aplica.

## Caso ambiguo
Caso con indicadores a favor y en contra de ¿cuántas veces se puede prorrogar una incapacidad laboral?. Depende de hechos decisivos a verificar. Requiere analisis adicional.

## Caso excluido
Situacion que no cumple ningun elemento de ¿cuántas veces se puede prorrogar una incapacidad laboral?. La regla no aplica y no hay derecho ni obligacion derivada.

## Caso excepcional
Situacion que cumple los elementos de ¿cuántas veces se puede prorrogar una incapacidad laboral? pero activa una excepcion normativa (fuero, plazo, regimen especial). Requiere verificacion con la norma oficial.

## Caso con prueba suficiente

## Caso con prueba insuficiente
El consultante no tiene contrato escrito ni comprobantes sobre ¿cuántas veces se puede prorrogar una incapacidad laboral?. La conclusion depende de indicios y requiere recolectar mas evidencia.

## Caso con norma o termino temporal relevante
